# D3. 자세 채점 스펙 (Posture Scoring Spec)

> 상태: v0 (초안). 모든 가중치·태그 임계값은 "v0 — D6 데이터로 확정"으로 표기된 잠정값이며, 검증 프로토콜(D6)에서 수집한 실측 데이터로 확정되기 전까지는 변경 가능하다.
> 본 문서는 `docs/spec-rep-detection.md`(D2)가 산출하는 **rep 지표**(D2 지표)만을 입력으로 받는 순수 채점 규칙을 정의한다. 카메라·포즈 추정·rep 판정(카운트 여부) 로직은 D2 소관이며 본 문서는 다루지 않는다.

## 0. 입력 (D2 지표 재사용)

D2가 매 rep마다 산출해 `shared:core`에 전달하는 rep 지표 중 본 문서가 사용하는 항목은 다음과 같다 (정확한 필드명·스키마는 D2 문서를 따르며, 여기서는 의미로만 참조한다):

| D2 지표 (의미) | 단위 | 채점에서의 역할 |
|---|---|---|
| 팔꿈치 각도 ∠(어깨-팔꿈치-손목), 좌·우 각각 | ° | ROM, 하단 완전 신전, 좌우 대칭의 원재료 |
| TOP 이벤트 시점의 좌우 평균 팔꿈치 각도 | ° | ROM 상단값, 턱-바 미달 판정 보조 |
| BOTTOM(신전 확정) 시점의 좌우 평균 팔꿈치 각도 | ° | ROM 하단값, 하단 완전 신전 |
| 골반 중점 수평 변위 / 어깨폭(S) | 무차원 | 키핑 |
| rep 시작~종료 시간(센서 타임스탬프 차, ms) | ms | 템포 일관성 |
| rep 유효/노카운트 사유 (엄격 모드 미충족 등) | enum | 태그 판정, 세션 채점 대상 여부 |
| `AUX` 플래그(보조 지표로 TOP 확정된 rep, D2 §5.4) | bool | 카운트 포함 + `UNDETERMINED_OCCLUSION` 태그(채점 제외) 처리 |

채점 대상 rep 집합:
- **엄격 모드**: D2가 "유효(카운트됨)"로 판정한 rep만 채점 대상. (노카운트 rep은 세션 리포트의 "노카운트 이력"에는 남지만 아래 하위 점수 평균 계산에는 포함하지 않는다 — 애초에 카운트되지 않으므로 자세 점수 대상이 아니다.)
- **연습 모드**: D2가 카운트한 모든 rep(완전/불완전 포함)이 채점 대상. 불완전 rep은 §3의 감점 규칙을 추가로 적용한다.
- **가림 관련 rep (D2 §5.4)**: D2는 가림 정도에 따라 카운트 여부가 다른 두 rep을 구분하며, D3는 이 구분을 그대로 따른다.
  - **`AUX` 플래그 rep**(얼굴 가림 캡 초과 후 보조 지표로 TOP이 확정되어 D2가 **카운트한** rep): 아래 §1의 4개 하위 점수(ROM·키핑·좌우대칭·하단 신전) 평균 계산에서는 제외한다(신뢰할 수 없는 값이므로). 단 세션 rep 카운트에는 포함되고, `UNDETERMINED_OCCLUSION` 태그로 리포트에 표시된다. 템포 일관성 계산에서는 rep 길이(시작~종료 시간)는 가림 여부와 무관하게 유효하므로 그대로 포함한다.
  - **`UNDECIDABLE` rep**(얼굴·보조 지표 모두 쓸 수 없어 D2가 판정 자체를 내리지 못한 rep, D2 §5.4·§7.2 E7): 엄격·연습 모두 D2 단계에서 **노카운트**로 처리된다(D2 사유 코드 `UNDETERMINED_OCCLUSION`, N4). 이런 rep은 D3의 세션 rep 카운트, 4개 하위 점수 평균, 템포 일관성 계산 어디에도 포함하지 않는다 — 다른 노카운트 사유(`INCOMPLETE_EXTENSION` 등)와 동일하게 애초에 채점 대상 rep 집합에 들어오지 않는다.

## 1. 항목별 0–100 하위 점수 산식

모든 산식은 **rep 지표 값 → 점수**의 순수 함수이며, `clamp(x, 0, 1) = max(0, min(1, x))`로 표기한다. ROM·키핑·좌우대칭·하단 완전 신전은 **rep별로 계산 후 세션 내 유효 rep에 대해 산술평균**하여 세션 단위 하위 점수(0–100)를 만든다. 템포 일관성은 세션 전체 rep 길이 집합에 대해 한 번만 계산한다.

### 1.1 가동 범위 (ROM)
```
ROM_actual(rep)  = θ_bottom(rep) − θ_top(rep)          [°]
ROM_ratio(rep)   = clamp(ROM_actual(rep) / ROM_ideal, 0, 1)
score_ROM(rep)   = 100 × ROM_ratio(rep)
```
- `ROM_ideal = 130°` (v0 — D6 데이터로 확정). 가정: 완전 신전(θ_ext strict 초기 160°대 부근) ~ 턱-바 통과 시점의 팔꿈치 각도(초기 약 30°) 사이의 이상적 구간폭.
- 세션 하위 점수 = 유효 rep들의 `score_ROM(rep)` 산술평균.

### 1.2 키핑 (반동)
```
H(rep)          = max(|골반 중점 수평 변위(t)|) / S     (rep 구간 내 최댓값, 무차원)
score_kip(rep)  = 100 × clamp( (H1 − H(rep)) / (H1 − H0), 0, 1 )
```
- `H0 = 0.05`, `H1 = 0.30` (v0 — D6 데이터로 확정). `H(rep) ≤ H0`이면 100점(반동 없음으로 간주), `H(rep) ≥ H1`이면 0점.
- 세션 하위 점수 = 유효 rep들의 `score_kip(rep)` 산술평균.

### 1.3 템포 일관성
```
μ    = mean(T_1, …, T_n)                (n = 세션 내 유효 rep 길이 개수, ms)
σ    = population_stdev(T_1, …, T_n)     (모집단 표준편차, n으로 나눔)
CV   = σ / μ
score_tempo = 100 × clamp(1 − CV / CV_max, 0, 1)
```
- `CV_max = 0.35` (v0 — D6 데이터로 확정).
- n < 2인 세션(유효 rep 1개 이하)은 변동을 정의할 수 없으므로 `score_tempo = 100`(중립값)으로 고정하고 리포트에 "표본 부족" 주석을 남긴다.

### 1.4 좌우 대칭
```
Δelbow(rep)     = |θ_left,TOP(rep) − θ_right,TOP(rep)|   [°]
score_sym(rep)  = 100 × clamp(1 − Δelbow(rep) / Δmax, 0, 1)
```
- `Δmax = 20°` (v0 — D6 데이터로 확정).
- 세션 하위 점수 = 유효 rep들의 `score_sym(rep)` 산술평균.

### 1.5 하단 완전 신전
```
score_ext(rep) = 100 × clamp( (θ_bottom(rep) − θ_min) / (θ_full − θ_min), 0, 1 )
```
- `θ_min = 140°`, `θ_full = 180°` (v0 — D6 데이터로 확정). `θ_min`은 "명백히 안 편 것으로 간주"하는 하한, `θ_full`은 해부학적 완전 신전.
- 세션 하위 점수 = 유효 rep들의 `score_ext(rep)` 산술평균.

## 2. 초기 가중치 (v0 — D6 데이터로 확정)

| 항목 | 가중치 |
|---|---|
| 가동 범위 (ROM) | 0.30 |
| 키핑 | 0.25 |
| 템포 일관성 | 0.15 |
| 좌우 대칭 | 0.15 |
| 하단 완전 신전 | 0.15 |
| **합계** | **1.00** |

```
SessionScore_raw = 0.30×score_ROM + 0.25×score_kip + 0.15×score_tempo
                 + 0.15×score_sym + 0.15×score_ext
```

## 3. 연습 모드 불완전 rep 감점

**불완전 rep 정의**: `ROM_ratio(rep) < 0.6` (§1.1과 동일한 `ROM_ideal`을 사용, v0 — D6 데이터로 확정). 이 정의는 연습 모드 자세 채점 전용이며, D2의 카운트 여부 판정 로직과 독립적이다(연습 모드는 완전/불완전 관계없이 오르내림이 있으면 카운트하므로, 채점 단계에서 별도로 "불완전"을 정의해 감점한다).

```
IncompleteCount = 세션 내 불완전 rep 개수
Penalty         = min(20, 5 × IncompleteCount)
SessionScore    = clamp(SessionScore_raw − Penalty, 0, 100)     [연습 모드에만 적용]
```

- **엄격 모드**에서는 이 감점 항이 존재하지 않는다(`Penalty = 0`). 엄격 모드는 불완전 rep을 애초에 카운트하지 않으므로 채점 대상에 포함되지 않는다.
- 감점은 5점 단위로 고정(rep마다 5점, 세션 최대 20점 캡)이며, 하위 점수 산식과 마찬가지로 난수·시간 요소가 없다.

## 4. 실패 태그 enum과 판정 규칙

```
enum FailureTag {
  CHIN_BELOW_BAR,        // 턱이 바를 충분히 넘지 못함 (상단 높이 부족)
  INCOMPLETE_EXTENSION,  // 하단에서 팔이 충분히 펴지지 않음
  KIPPING,               // 반동(골반/몸통 흔들림) 과다
  ASYMMETRY,             // 좌우 비대칭 과다
  TEMPO_INCONSISTENT,    // 반복 간 속도 편차 과다
  UNDETERMINED_OCCLUSION // 가림 등으로 판정 불가(점수 미반영)
}
```

### 4.1 rep 단위 태그 판정 (D2 지표 기반, v0 — D6 데이터로 확정)

| 태그 | 판정 조건 | 관련 하위 점수 카테고리 |
|---|---|---|
| `UNDETERMINED_OCCLUSION` | D2가 해당 rep에 `AUX` 플래그를 붙임(보조 지표로 TOP 확정, D2가 카운트한 rep만 해당). D2가 노카운트로 처리한 `UNDECIDABLE` rep은 애초에 채점 대상 rep 집합에 들어오지 않으므로 이 태그 판정 자체가 적용되지 않는다 | 없음(채점 제외, 별도 표시) |
| `CHIN_BELOW_BAR` | (연습 모드) `ROM_ratio(rep) < 0.6`, 즉 상단 높이 부족으로 인한 불완전 | ROM |
| `INCOMPLETE_EXTENSION` | `θ_bottom(rep) < θ_min (140°)` | 하단 완전 신전 |
| `KIPPING` | `H(rep) ≥ H_tag (0.15)` | 키핑 |
| `ASYMMETRY` | `Δelbow(rep) ≥ Δtag (10°)` | 좌우 대칭 |
| `TEMPO_INCONSISTENT` | 세션 단위: `CV ≥ CV_tag (0.20)` — 개별 rep이 아닌 세션 전체에 부여, 평균에서 `|T_i − μ| > σ`인 rep을 "느림/빠름" 참고 표시로 함께 보여줌 | 템포 일관성 |

`H_tag(0.15)`, `Δtag(10°)`, `CV_tag(0.20)`은 각각 §1의 `H0/H1`, `Δmax`, `CV_max` 사이의 v0 잠정값이며 모두 "v0 — D6 데이터로 확정" 대상이다.

### 4.2 세션 요약 태그 (팁 카테고리 매핑)

리포트 상단에는 아래 5개 채점 카테고리 중 감점이 발생한 항목만 표시하고, 각 카테고리는 정확히 1개의 태그에 대응한다(태그와 카테고리는 1:1):

| 채점 카테고리 | 대응 태그 |
|---|---|
| ROM | `CHIN_BELOW_BAR` |
| 하단 완전 신전 | `INCOMPLETE_EXTENSION` |
| 키핑 | `KIPPING` |
| 좌우 대칭 | `ASYMMETRY` |
| 템포 일관성 | `TEMPO_INCONSISTENT` |

`UNDETERMINED_OCCLUSION`은 카테고리 랭킹에 참여하지 않는 별도 데이터 품질 표시로, 세션 내 1개 이상의 rep에 `AUX` 플래그(카운트되었으나 보조 지표로 확정된 rep)가 있었다면 항상 리포트에 노출한다(팁 선택 순위와 무관). D2가 노카운트로 버린 `UNDECIDABLE` rep은 이 표시의 대상이 아니다.

## 5. 팁 라이브러리 스키마와 선택 규칙

### 5.1 스키마

```
TipEntry {
  tagId: FailureTag     // 위 enum 값
  tipRank: Int          // 1부터 시작하는 고정 순번(같은 tagId 내 우선순위, 결정적 선택에 사용)
  message: String       // 한국어 코칭 문구
}
```

### 5.2 팁 목록 (태그당 ≥2개)

**CHIN_BELOW_BAR**
1. 턱이 바 위로 완전히 올라오지 않았습니다. 정수리가 아니라 턱 끝이 바를 넘는 지점까지 당겨보세요.
2. 가동 범위가 부족합니다. 팔을 완전히 편 지점부터 턱이 바를 넘는 지점까지 전체 구간을 사용하세요.

**INCOMPLETE_EXTENSION**
1. 하단에서 팔이 완전히 펴지지 않았습니다. 다음 반복을 시작하기 전에 팔꿈치를 끝까지 펴고 잠깐 멈추세요.
2. 세트 후반에 팔을 덜 펴는 경향이 있습니다. 반복 수가 줄더라도 매 회 완전 신전을 유지하세요.

**KIPPING**
1. 몸통과 골반이 앞뒤로 흔들리고 있습니다(반동). 코어에 힘을 주고 몸통을 일직선으로 고정한 채 당기세요.
2. 반동을 줄이려면 속도를 늦추고, 다리를 곧게 펴거나 가볍게 교차해 흔들림을 억제해 보세요.
3. 반동이 심하면 엄격 모드에서 정상 rep으로 인정되지 않을 수 있습니다. 리더보드 도전 전에 반동부터 줄이세요.

**ASYMMETRY**
1. 좌우 팔꿈치 각도 차이가 큽니다. 영상을 다시 보며 양팔이 동시에 펴지고 굽혀지는지 확인하세요.
2. 한쪽 어깨나 팔에 힘이 더 들어가고 있을 수 있습니다. 그립 너비와 좌우 손 위치가 대칭인지 점검하세요.

**TEMPO_INCONSISTENT**
1. 반복 간 속도 편차가 큽니다. 일정한 카운트(예: 올라가기 1초, 내려가기 2초)로 템포를 맞춰보세요.
2. 세트 후반으로 갈수록 느려지고 있습니다. 처음부터 끝까지 유지 가능한 속도로 시작하세요.

**UNDETERMINED_OCCLUSION**
1. 일부 구간에서 얼굴/손목이 가려져 판정이 불확실했습니다. 카메라 각도를 조정하거나 손목 보호대를 낮춰 착용해 보세요.
2. 가림 시간이 길면 해당 반복은 채점에서 제외됩니다. 바 그립 위치와 카메라 거리를 조정해 가림을 줄이세요.

### 5.3 선택 규칙

1. §4.2의 5개 채점 카테고리에 대해 **가중 감점** `penalty_c = (100 − score_c) × weight_c`를 계산한다(`score_c`, `weight_c`는 §1·§2의 해당 카테고리 세션 하위 점수·가중치).
2. `penalty_c > 0`인 카테고리만 후보로 남긴다.
3. 후보를 `penalty_c` **내림차순**으로 정렬한다.
4. **동점 처리(고정 우선순위)**: `penalty_c` 값이 같으면 다음 고정 순서로 정렬한다 — `KIPPING` > `CHIN_BELOW_BAR` > `INCOMPLETE_EXTENSION` > `ASYMMETRY` > `TEMPO_INCONSISTENT` (부상 위험이 큰 항목 → rep 유효성 항목 → 폼 다듬기 항목 순).
5. 상위 **1~3개** 카테고리를 선택한다(후보가 3개 미만이면 있는 만큼만).
6. 선택된 각 카테고리의 태그에 대해 `tipRank = 1`인 팁 1개를 노출한다. 즉 최종 팁 개수 = 선택된 카테고리 개수(1~3개).
7. 후보가 0개(모든 `penalty_c = 0`)이면 태그·팁 없이 고정 문구 "만점 세트! 교정할 항목이 없습니다."를 표시한다.

동일한 입력(동일 rep 지표 시퀀스)은 위 1–7단계를 거쳐 항상 동일한 카테고리 순서와 동일한 팁을 산출한다(무작위 선택 없음).

## 6. 결정성(Determinism) 선언

- 위 모든 산식(§1~§5)은 **rep 지표 값에 대한 순수 함수**이며, 동일한 rep 지표 시퀀스가 입력되면 하위 점수·세션 점수·태그 목록·팁 목록이 항상 동일하게 산출된다.
- 난수 생성기를 사용하지 않는다. 동점 처리는 고정 우선순위 표(§5.3-4)로만 해결한다.
- 실행 시각(wall-clock)이나 실시간 시계에 의존하지 않는다. 유일한 시간 관련 입력은 rep 메타데이터에 이미 기록된 **rep 길이(ms, 센서 타임스탬프 차)**이며, 이는 "지금이 몇 시인지"가 아니라 "이미 기록된 값"에 대한 함수이므로 결정성을 해치지 않는다.
- 실행 기기의 하드웨어 성능, OS 버전, 배터리 상태 등 기기 정보에 의존하는 항 없음.
- 이 성질은 `shared:core`(KMP 공통 모듈)의 단위 테스트로 검증한다: 동일 입력 rep 지표 시퀀스를 N회 반복 채점해 출력이 모두 바이트 단위로 동일함을 확인한다.

## 7. 워크드 예제

아래 세 예제는 §1~§5의 산식을 실제 숫자로 손계산한 것이다. `clamp`는 계산 후 0–1 범위로 자른다는 뜻이며, 별도 언급이 없으면 클리핑이 발생하지 않았다.

### 예제 1 — 완벽한 세트 (엄격 모드, 5 rep)

입력(모든 rep 동일):
- θ_top = 30°, θ_bottom = 180° → `ROM_actual = 180 − 30 = 150`
- H = 0.02, Δelbow = 0°, rep 길이 = 2000 ms (5개 모두 동일)

계산:
- ROM: `ROM_ratio = clamp(150/130, 0,1) = clamp(1.1538, 0,1) = 1.0` → `score_ROM = 100`
- 키핑: `score_kip = 100 × clamp((0.30−0.02)/0.25,0,1) = 100 × clamp(1.12,0,1) = 100`
- 템포: T = [2000,2000,2000,2000,2000] → μ=2000, σ=0, CV=0 → `score_tempo = 100`
- 대칭: `score_sym = 100 × clamp(1 − 0/20,0,1) = 100`
- 하단 신전: `score_ext = 100 × clamp((180−140)/40,0,1) = 100`

세션 점수:
```
SessionScore_raw = 0.30×100 + 0.25×100 + 0.15×100 + 0.15×100 + 0.15×100 = 100
```
엄격 모드이므로 감점 없음. **최종 점수 = 100.**
가중 감점 `penalty_c`가 5개 카테고리 모두 0 → 태그 없음. 팁: "만점 세트! 교정할 항목이 없습니다."

### 예제 2 — 반동(키핑)이 있는 세트 (엄격 모드, 5 rep, 모두 유효 카운트)

입력(모든 rep 동일):
- θ_top = 30°, θ_bottom = 180° (ROM·하단 신전은 정상)
- H = 0.20 (반동 큼), Δelbow = 4°
- rep 길이 = [1900, 2000, 2100, 1950, 2050] ms

계산:
- ROM: `ROM_actual=150` → 예제1과 동일 → `score_ROM = 100`
- 키핑: `score_kip = 100 × clamp((0.30−0.20)/0.25,0,1) = 100 × clamp(0.10/0.25,0,1) = 100×0.4 = 40`
- 템포: μ = (1900+2000+2100+1950+2050)/5 = 10000/5 = 2000
  편차: −100, 0, 100, −50, 50 → 제곱합 = 10000+0+10000+2500+2500 = 25000
  σ² = 25000/5 = 5000 → σ = √5000 ≈ 70.71 → `CV = 70.71/2000 ≈ 0.0354`
  `score_tempo = 100 × clamp(1 − 0.0354/0.35,0,1) = 100×(1−0.1010) ≈ 89.9`
- 대칭: `score_sym = 100 × clamp(1 − 4/20,0,1) = 100×0.8 = 80`
- 하단 신전: `score_ext = 100 × clamp((180−140)/40,0,1) = 100`

세션 점수:
```
SessionScore_raw = 0.30×100 + 0.25×40 + 0.15×89.9 + 0.15×80 + 0.15×100
                 = 30 + 10 + 13.485 + 12 + 15 = 80.485 ≈ 80.5
```
엄격 모드, 감점 없음. **최종 점수 ≈ 80.5.**

태그/팁 선정 — 카테고리별 가중 감점 `(100−score_c)×weight_c`:
- ROM: (100−100)×0.30 = 0
- 키핑: (100−40)×0.25 = **15.0**
- 템포: (100−89.9)×0.15 ≈ 1.515
- 대칭: (100−80)×0.15 = **3.0**
- 하단 신전: 0

내림차순: 키핑(15.0) > 대칭(3.0) > 템포(1.515). 3개 모두 >0이므로 상위 3개 모두 채택.
**태그: `KIPPING`, `ASYMMETRY`, `TEMPO_INCONSISTENT`** (이 순서로).
**팁(각 카테고리 tipRank=1):**
1. (KIPPING) "몸통과 골반이 앞뒤로 흔들리고 있습니다(반동). 코어에 힘을 주고 몸통을 일직선으로 고정한 채 당기세요."
2. (ASYMMETRY) "좌우 팔꿈치 각도 차이가 큽니다. 영상을 다시 보며 양팔이 동시에 펴지고 굽혀지는지 확인하세요."
3. (TEMPO_INCONSISTENT) "반복 간 속도 편차가 큽니다. 일정한 카운트로 템포를 맞춰보세요."

### 예제 3 — 하프렙이 섞인 연습 세트 (연습 모드, 4 rep: 완전 2 + 하프렙 2)

입력:
| rep | θ_top | θ_bottom | H | Δelbow | 길이(ms) |
|---|---|---|---|---|---|
| 1 (완전) | 30° | 180° | 0.03 | 2° | 2000 |
| 2 (완전) | 30° | 180° | 0.03 | 2° | 2100 |
| 3 (하프렙) | 110° | 180° | 0.03 | 2° | 1300 |
| 4 (하프렙) | 110° | 180° | 0.03 | 2° | 1250 |

rep별 ROM:
- rep1,2: `ROM_actual = 180−30 = 150` → `ROM_ratio = clamp(150/130,0,1)=1.0` → `score_ROM=100`
- rep3,4: `ROM_actual = 180−110 = 70` → `ROM_ratio = 70/130 = 0.5385` → `score_ROM = 53.8`
  → `0.5385 < 0.6`이므로 rep3, rep4는 **불완전 rep**(§3) + **`CHIN_BELOW_BAR`** 태그 대상.

ROM 세션 하위 점수(평균): `(100+100+53.8+53.8)/4 = 307.6/4 = 76.9`

rep별 키핑: 전 rep H=0.03 ≤ H0(0.05) → `score_kip=100` (모두) → 세션 평균 `= 100`

rep별 대칭: 전 rep Δelbow=2° → `score_sym = 100×clamp(1−2/20,0,1) = 90` (모두) → 세션 평균 `= 90`

rep별 하단 신전: 전 rep θ_bottom=180° → `score_ext=100` (모두) → 세션 평균 `= 100`

템포: T = [2000, 2100, 1300, 1250]
```
μ = (2000+2100+1300+1250)/4 = 6650/4 = 1662.5
편차: 337.5, 437.5, −362.5, −412.5
제곱: 113906.25, 191406.25, 131406.25, 170156.25 → 합 = 606875
σ² = 606875/4 = 151718.75 → σ ≈ 389.51
CV = 389.51 / 1662.5 ≈ 0.2343
score_tempo = 100 × clamp(1 − 0.2343/0.35, 0,1) = 100×(1−0.6694) ≈ 33.1
```

세션 점수(감점 전):
```
SessionScore_raw = 0.30×76.9 + 0.25×100 + 0.15×33.1 + 0.15×90 + 0.15×100
                 = 23.07 + 25 + 4.965 + 13.5 + 15 = 81.535 ≈ 81.5
```

연습 모드 불완전 rep 감점: `IncompleteCount = 2` (rep3, rep4) → `Penalty = min(20, 5×2) = 10`
```
SessionScore = clamp(81.5 − 10, 0, 100) = 71.5
```
**최종 점수 = 71.5.**

태그/팁 선정 — 카테고리별 가중 감점:
- ROM: (100−76.9)×0.30 = 23.1×0.30 = **6.93**
- 키핑: (100−100)×0.25 = 0
- 템포: (100−33.1)×0.15 = 66.9×0.15 = **10.035**
- 대칭: (100−90)×0.15 = 10×0.15 = **1.5**
- 하단 신전: 0

내림차순: 템포(10.035) > ROM(6.93) > 대칭(1.5). 3개 모두 >0 → 상위 3개 채택.
**태그(세션 요약): `TEMPO_INCONSISTENT`, `CHIN_BELOW_BAR`, `ASYMMETRY`** (이 순서).
**rep별 타임라인 태그**: rep3, rep4 각각 `CHIN_BELOW_BAR`(상단 높이 부족으로 불완전).
**팁:**
1. (TEMPO_INCONSISTENT) "반복 간 속도 편차가 큽니다. 일정한 카운트로 템포를 맞춰보세요."
2. (CHIN_BELOW_BAR) "턱이 바 위로 완전히 올라오지 않았습니다. 정수리가 아니라 턱 끝이 바를 넘는 지점까지 당겨보세요."
3. (ASYMMETRY) "좌우 팔꿈치 각도 차이가 큽니다. 영상을 다시 보며 양팔이 동시에 펴지고 굽혀지는지 확인하세요."

리포트에는 별도로 "연습 모드 불완전 rep 감점: −10점 (2회, rep 3·4)"를 감점 근거로 함께 표시한다(팁 카테고리 순위와는 별개의 항목).

## 8. 가중치 확정 절차 (v0 → v1)

1. **데이터 수집(D6)**: 검증 프로토콜(D6)에서 실제 세션 n≥100건에 대해 (a) 본 문서 v0 산식으로 계산한 하위 점수·세션 점수, (b) 사람(운영자/코치)이 별도로 매긴 자세 등급 또는 순위를 함께 기록한다.
2. **정합성 분석**: v0 하위 점수와 사람 평가 간 상관·순위 일치도를 카테고리별로 분석해, 가중치 재조정이 필요한 카테고리를 식별한다.
3. **재조정 제약**: 각 가중치는 v0 값 대비 **±0.10** 범위 내에서만 조정하고, 조정 후 5개 가중치의 합이 다시 1.00이 되도록 정규화한다. 산식 형태(§1의 수식) 자체는 이 절차로 바꾸지 않는다 — 형태 변경은 별도 스펙 개정(major 버전)으로 다룬다.
4. **버전 증가**: 가중치(또는 태그 임계값)가 변경되면 본 문서 상단의 버전 표기를 `v0 → v1`로 올리고, 문서 하단 변경 이력에 변경된 값·근거 데이터 건수·날짜를 기록한다. 이후 표기는 더 이상 "v0 — D6 데이터로 확정"이 아니라 "v1 — 확정값(202X-XX-XX, n=YYY)"로 바뀐다.
5. **하위 호환/재현성**: 과거에 저장된 세션 리포트는 채점 당시의 가중치 버전 번호를 함께 저장해, 버전이 올라간 뒤에도 과거 리포트를 재계산하지 않고 원래 값 그대로 조회할 수 있게 한다(결정성 선언 §6과 일관: "동일 입력 + 동일 버전 → 동일 출력"이 항상 성립해야 하며, 버전이 바뀌면 새 버전으로 명시적으로 재채점해야만 값이 달라진다).
